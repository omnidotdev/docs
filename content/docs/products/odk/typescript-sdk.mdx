The TypeScript SDK lets you define schemas using Zod, ArkType, or Valibot, then emit to any TypeSpec target.

## Installation

```sh
bun add @omnidotdev/odk zod
# or
npm install @omnidotdev/odk zod
```

## Quick Start

```typescript
import { odk } from "@omnidotdev/odk";
import { z } from "zod";

const User = z.object({
  id: z.string().uuid(),
  email: z.string().email(),
  name: z.string().optional(),
});

const schema = odk.schema("MyAPI", { User });

// Get TypeSpec source
const tsp = odk.toTypeSpec(schema);

// Or emit to targets
await odk.emit(schema, {
  targets: ["@typespec/openapi3"],
  outDir: "./generated",
});
```

## API Reference

### `odk.schema(name, types, options?)`

Create an ODK schema from Standard Schema types.

```typescript
const schema = odk.schema("MyAPI", { User, Post }, {
  description: "My API schema",
  imports: ["@typespec/http"],
});
```

**Parameters:**
- `name` - Namespace name for the schema
- `types` - Record of named types (Zod, ArkType, or Valibot schemas)
- `options` - Optional configuration
  - `description` - Schema documentation
  - `imports` - TypeSpec imports to include
  - `suppressWarnings` - Suppress non-serializable warnings

**Returns:** `ODKSchema` object

### `odk.emit(schema, options)`

Emit schema to target formats.

```typescript
await odk.emit(schema, {
  targets: ["@typespec/openapi3", "@typespec/protobuf"],
  outDir: "./generated",
  tspConfig: "./tspconfig.yaml",
});
```

**Parameters:**
- `schema` - ODK schema from `odk.schema()`
- `options`
  - `targets` - Array of TypeSpec emitter packages
  - `outDir` - Output directory
  - `tspConfig` - Path to tspconfig.yaml (optional)

### `odk.toTypeSpec(schema, namespace?)`

Generate TypeSpec source code.

```typescript
const source = odk.toTypeSpec(schema);
console.log(source);
```

**Returns:** TypeSpec source as string

### `odk.toJSON(schema)`

Serialize schema to JSON for the Rust CLI.

```typescript
const json = odk.toJSON(schema);
await Bun.write("schema.json", json);
```

**Returns:** JSON string of CompiledSchema

### `odk.getCompiled(schema)`

Get the compiled schema IR.

```typescript
const compiled = odk.getCompiled(schema);
console.log(compiled.models);
```

**Returns:** `CompiledSchema` object

### `odk.raw(schema, content, description?)`

Add raw TypeSpec code (escape hatch).

```typescript
odk.raw(schema, `
  @route("/api")
  interface MyApi {
    @get health(): void;
  }
`, "API routes");
```

### `odk.addImport(schema, importPath)`

Add a TypeSpec import.

```typescript
odk.addImport(schema, "@typespec/http");
odk.addImport(schema, "@omnidotdev/typespec-drizzle");
```

## Supported Schema Libraries

### Zod

```typescript
import { z } from "zod";

const User = z.object({
  id: z.string().uuid(),
  email: z.string().email(),
  age: z.number().int().min(0).max(150),
  role: z.enum(["admin", "user"]),
  tags: z.array(z.string()),
  metadata: z.record(z.string()),
});
```

### ArkType

```typescript
import { type } from "arktype";

const User = type({
  id: "string",
  email: "email",
  age: "integer >= 0",
  role: "'admin' | 'user'",
});
```

### Valibot

```typescript
import * as v from "valibot";

const User = v.object({
  id: v.pipe(v.string(), v.uuid()),
  email: v.pipe(v.string(), v.email()),
  age: v.pipe(v.number(), v.integer(), v.minValue(0)),
});
```

## Type Mapping

| Zod | TypeSpec |
|-----|----------|
| `z.string()` | `string` |
| `z.string().uuid()` | `string` with format |
| `z.string().email()` | `string` with format |
| `z.number()` | `float64` |
| `z.number().int()` | `int64` |
| `z.boolean()` | `boolean` |
| `z.date()` | `utcDateTime` |
| `z.array(T)` | `T[]` |
| `z.object({})` | `model` |
| `z.enum([])` | `union` |
| `z.union([])` | `union` |
| `z.optional()` | `?` modifier |

## Constraints

Zod constraints are mapped to TypeSpec decorators:

```typescript
const User = z.object({
  name: z.string().min(1).max(100),  // @minLength(1) @maxLength(100)
  age: z.number().min(0).max(150),   // @minValue(0) @maxValue(150)
  email: z.string().regex(/^.+@.+$/), // @pattern("^.+@.+$")
});
```

## Non-Serializable Features

Some Zod features cannot be serialized to TypeSpec:

```typescript
const User = z.object({
  email: z.string()
    .transform(s => s.toLowerCase())  // Warning: not serializable
    .refine(isValidEmail),            // Warning: not serializable
});
```

These generate warnings but don't break emission. Store them in extensions:

```typescript
// Future API for preserving transforms
const User = z.object({
  email: z.string().transform(s => s.toLowerCase()),
});

// Extensions preserve the transform code as metadata
```

## Using with Rust CLI

Export schema JSON for the Rust CLI:

```typescript
const schema = odk.schema("MyAPI", { User });
const json = odk.toJSON(schema);
await Bun.write("schema.json", json);
```

Then compile with:

```sh
odk compile schema.json -o generated/
```

## Complete Example

```typescript
import { odk } from "@omnidotdev/odk";
import { z } from "zod";

// Define types
const UserRole = z.enum(["admin", "author", "reader"]);

const User = z.object({
  id: z.string().uuid(),
  email: z.string().email(),
  username: z.string().min(3).max(32),
  role: UserRole,
  createdAt: z.date(),
});

const Post = z.object({
  id: z.string().uuid(),
  title: z.string().min(1).max(200),
  content: z.string(),
  authorId: z.string().uuid(),
  status: z.enum(["draft", "published"]),
});

// Create schema
const schema = odk.schema("BlogAPI", 
  { User, Post, UserRole },
  { imports: ["@typespec/http"] }
);

// Add API routes
odk.raw(schema, `
  @route("/posts")
  interface Posts {
    @get list(): Post[];
    @post create(@body post: Post): Post;
  }
`);

// Emit
await odk.emit(schema, {
  targets: ["@typespec/openapi3"],
  outDir: "./generated",
});
```
