The **Omni Development Kit (ODK)** turns a single schema into the specs, database schemas, and typed SDKs your stack needs. Define your models once in YAML, TypeScript, Rust, or Python; a Rust CLI compiles them through a shared intermediate representation (TypeSpec) to any emitter, and a WASM plugin SDK lets you add emitters of your own.

## Key features

- **Define once, in your language**: author schemas in YAML, TypeScript (with Zod, ArkType, or Valibot), Rust, or Python, or load them from GraphQL SDL.
- **Compile to specs and schemas**: emit OpenAPI and JSON Schema by default, plus Protocol Buffers and Drizzle ORM, through TypeSpec emitters.
- **Generate typed clients**: from a GraphQL schema and operations, produce a typed SDK, React Query hooks, and MSW mock handlers.
- **Types in every language**: emit idiomatic TypeScript, Rust, and Python models, including recursive, data-carrying discriminated unions.
- **Extend with WASM plugins**: write custom emitters in Rust or Python with the plugin development kit (PDK), hosted via Extism.
- **One Rust binary, open source**: a single CLI with no runtime to manage, licensed Apache 2.0.

## How it works

ODK is a one-to-many transformation pipeline built around a shared IR:

```
Your schema (YAML, TypeScript, Rust, Python, or GraphQL)
            |
            v
     CompiledSchema IR
            |
            v
        TypeSpec  ──────────────► OpenAPI, JSON Schema, Protobuf, Drizzle, ...
            |
            └─ generate ────────► typed SDK, React Query hooks, MSW mocks,
                                   TypeScript / Rust / Python models
```

`odk compile` runs the schema through TypeSpec to spec and schema emitters; `odk generate` produces typed client artifacts and language models directly. Both read the same IR, so every output stays consistent with the source.
