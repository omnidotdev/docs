**Facet** is code-first parametric CAD that runs entirely in your browser. You write a model as code, a solid-geometry (CSG) kernel evaluates it into a mesh, a 3D viewport shows it live, and you export a print-ready STL. Nothing installs and nothing leaves the tab.

Think script-based modeling, but authored in a real programming language: primitives, transforms, and boolean operations compose with variables, loops, and functions, and named parameters become live sliders.

## Write code, get geometry

A model is a snippet that builds a shape and returns it:

```ts
const base = cube([40, 40, 5], { center: false });
const hole = cylinder(3.2, 20, { segments: 32 });
return base.subtract(hole.translate(20, 20, 2.5));
```

Each call builds an op-graph rather than computing geometry directly. When you stop typing, Facet evaluates that graph with the active kernel, tessellates it to triangles, and reframes the viewport. Change a number and the solid updates in place.

## Key Features

- **Code-first authoring**, primitives (`cube`, `sphere`, `cylinder`), chainable transforms, and boolean operations, written in a TypeScript-flavored language
- **Live parameters**, declare `param.number(...)` and Facet renders a slider that recomputes the model as you drag it
- **Two kernels**, a TypeScript CSG kernel and a Rust kernel compiled to WebAssembly, selectable at runtime behind one interface
- **Live 3D viewport**, a flat-shaded, Z-up preview that reframes on demand and shows triangle count and evaluation time
- **STL export**, download a binary STL of the current model, ready for a slicer
- **Built-in examples**, load a starter model (parametric plate, L-bracket, bolt flange, and more) and edit it in place
- **Light and dark themes**, toggle with the theme button or the `T` key
- **Runs in the browser**, a static single-page app with no backend, self-hostable under Apache-2.0
