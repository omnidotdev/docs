## Do I own the code Keystone writes?

Yes. Download it at any time as plain HTML files from the
[live preview](/products/keystone/preview#download-your-code), or keep a copy in
your own GitHub repository with [GitHub Sync](/products/keystone/github-sync).
Either copy is yours to edit or host anywhere.

## Can I edit the code by hand and keep using Keystone?

Keystone does not read changes back from a download or a GitHub repository. Edits
made outside Keystone stay in your copy, and a later publish overwrites the pages
Keystone manages in a linked repository. Make changes in chat to keep them in
Keystone.

## Does publishing cost credits?

No. Only sending a prompt (and Enhance, which rewrites one) spends credits.
Publishing, previewing, downloading,
and syncing to GitHub are free. See [Credits](/products/keystone/credits).

## Do I need to republish after every change?

A preview link always shows the latest version of your site, so it updates on
its own. A hosted site updates only when you publish again. See
[Publishing](/products/keystone/publishing).

## Can I use my own domain?

Yes, for a site hosted on Fractal. Enter the domain when you select **Host on
Fractal**, then add the DNS records Keystone shows at your registrar. Custom
domains count toward your workspace's Fractal plan. A preview link has no custom
domain. See [Custom domains](/products/keystone/publishing#custom-domains).

## Can scripts I ask for run on my published site?

On a hosted site, yes. Each page's script (its animation, 3D, and
interactions) runs on the site's own address, and a page can load scripts only
from the site itself, Keystone's integration block runtime, and
[three.js](https://threejs.org). Scripts and event handlers written into the
HTML are removed on publish. A preview link is a still render, so no page
script runs there. See
[Scripts on hosted sites](/products/keystone/publishing#scripts-on-hosted-sites).

Interactive pieces such as product grids, buy buttons, and sign-up forms work
through [integration blocks](/products/keystone/integrations), and contact and
booking forms through [form blocks](/products/keystone/forms), which Keystone
wires up itself.

## What happens when I run out of credits?

Generation stops until you buy more credits or, on a paid plan, its included
credits renew. There
is never an automatic overage charge. See [Credits](/products/keystone/credits#running-out).

## Can I go back to an earlier site?

Yes. Select a site's card under **Your sites** to reopen it in the builder.
Opening the builder on its own starts a new site, created when you send the
first prompt; at your plan's site limit, the builder links to your most recent
site instead. See [Workspaces and Sites](/products/keystone/workspaces#sites).

To go back to an earlier version of a site, open its version history in the
builder and select **Undo last change** or **Restore**. See
[Version history and undo](/products/keystone/building#version-history-and-undo).

## How do I delete a site?

Select **Delete** in the site's card menu under **Your sites** and confirm.
Deleting cannot be undone. See
[Manage your sites](/products/keystone/workspaces#manage-your-sites).
