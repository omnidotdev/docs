## Do I own the code Keystone writes?

Yes. Download it at any time as plain HTML files from the
[live preview](/products/keystone/preview#download-your-code), or keep a copy in
your own GitHub repository with [GitHub Sync](/products/keystone/github-sync).
Either copy is yours to edit or host anywhere.

## Can I edit the code by hand and keep using Keystone?

Keystone does not read changes back from a download or a GitHub repository. Edits
made outside Keystone stay in your copy, and a later publish overwrites the pages
Keystone manages in a linked repository. Make changes in chat to keep them in
Keystone.

## Does publishing cost credits?

No. Only sending a prompt spends credits. Publishing, previewing, downloading,
and syncing to GitHub are free. See [Credits](/products/keystone/credits).

## Do I need to republish after every change?

A preview link always shows the latest version of your site, so it updates on
its own. A hosted site updates only when you publish again. See
[Publishing](/products/keystone/publishing).

## Can I use my own domain?

Custom domains are coming soon, with hosted sites, on Pro and Team. Today,
publishing gives a shareable preview link. See [Custom domains](/products/keystone/publishing#custom-domains).

## Can scripts I ask for run on my published site?

Published sites do not run custom page scripts: Keystone strips them on publish
for safety. Interactive pieces such as product grids, buy buttons, and sign-up
forms work through [integration blocks](/products/keystone/integrations), and
contact and booking forms through [form blocks](/products/keystone/forms), which
Keystone wires up itself.

## What happens when I run out of credits?

Generation stops until you buy more credits or, on a paid plan, its included
credits renew. There
is never an automatic overage charge. See [Credits](/products/keystone/credits#running-out).

## Can I go back to an earlier site?

Yes. Select a site's card under **Your sites** to reopen it in the builder.
Opening the builder on its own starts a new site, created when you send the
first prompt; at your plan's site limit, the builder links to your most recent
site instead. See [Workspaces and Sites](/products/keystone/workspaces#sites).
