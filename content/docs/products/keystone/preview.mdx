title: Live Preview
description: Check your site at every size, move between pages, and download the code
---

The preview panel shows your site as it stands after the latest turn. It runs in
an isolated frame, so nothing in the preview can affect the builder.

On phones, the builder shows one panel at a time: use the **Chat** and
**Preview** toggle in the header to switch. Sending a prompt switches to the
preview automatically.

## Device sizes

Use the size buttons in the preview toolbar to check your layout:

| Size | Width |
|------|-------|
| **Desktop** | The full width of the panel |
| **Tablet** | 820px |
| **Mobile** | 390px |

If a layout breaks at a smaller size, ask for a fix in chat, for example "polish
the layout for phones".

## Pages

A multi-page site shows a tab for each page above the preview. Select a tab to
view that page. Links between pages also work inside the preview: select a
navigation link and the preview moves to that page.

## Toolbar

| Control | What it does |
|---------|--------------|
| **Reload preview** | Re-renders the current page |
| **Open preview in a new tab** | Opens the current page full size in a new browser tab |
| **Download as HTML (.zip)** | Downloads the whole site as a `.zip` of HTML files |

## Download your code

**Download as HTML (.zip)** saves the whole site as `site.zip`, with every page
as a standalone HTML file laid out the way a static host serves it: the home
page at `index.html` and every other page at `<page>/index.html`. The download
is yours to keep, edit, or host anywhere, and it never spends credits.

<Callout type="info">
  [Integration blocks](/products/keystone/integrations) (live products, posts,
  and buy buttons) load live data in the preview and in the download too. The
  preview runs each page's script, so animation and 3D play there as they do
  on a [hosted site](/products/keystone/publishing#scripts-on-hosted-sites). A
  preview link shows a still version of the site instead.
</Callout>

## Follow-up suggestions

After each turn, one-tap suggestions such as **Add a contact form** or **Make it
bolder** appear under the chat. See [Building in Chat](/products/keystone/building).
