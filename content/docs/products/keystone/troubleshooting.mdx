---
title: Troubleshooting
description: Common Keystone messages and what to do about them
---

| Message or symptom | What it means | What to do |
|--------------------|---------------|------------|
| **Sign in to start building** | Building needs an Omni account | Select it and sign in, or create an account |
| **Verify your email address to start building.** | Your account's email address is not verified | Verify your email from your Omni account, then send again |
| **Keystone couldn't start your site.** or **Couldn't reach Keystone.** | The site could not be created just now; your prompt is kept | Select **Try again** |
| **Your session has ended.** or **Your session expired.** | Your sign-in expired | Select **Sign in again**; your prompt carries over |
| **Generation needs a workspace. Create or join one to continue.** | Your account is not in a workspace yet | Create or join a workspace, then try again. See [Workspaces and Sites](/products/keystone/workspaces) |
| **One of the attached images can't be used.** | An attached image didn't pass the automatic content check; nothing was sent or charged | Remove the image and send again |
| **Attached images can't be checked right now.** | The image check is briefly unavailable; nothing was sent or charged | Select **Try again** in a moment, or remove the images and send |
| **That PDF has no text Keystone can read** | The PDF is a scan or picture with no text in it | Attach a screenshot of it instead. See [Attach images and files](/products/keystone/building#attach-images-and-files) |
| **Attach images, PDFs, or plain text, Markdown, or CSV files.** | The file is a type Keystone doesn't read, such as a Word document, or isn't really the type its name says | Copy its text into a text file or the prompt |
| **You're out of AI credits. Buy more credits to keep generating.** | The credit balance of the site's workspace is used up | Select **Buy credits**, or, on a paid plan, wait for its included credits to renew. See [Credits](/products/keystone/credits) |
| **AI generation uses Omni credits.** | The workspace is on Free, has never bought credits, and has no free credits from a card | In your personal workspace, select **Add a card to unlock 50 free AI credits a month**. Or select **Buy credits**, or upgrade the workspace's plan. See [Credits](/products/keystone/credits#get-more-credits) |
| **This workspace has used today's free generation allowance. It resets at midnight UTC.** | A workspace that is not on a paid plan reached its daily generation limit | Wait until midnight UTC, or upgrade the workspace to a paid plan. See [Credits](/products/keystone/credits#daily-limit-without-a-paid-plan) |
| **You're generating quickly. Please wait a moment and try again.** | You sent prompts faster than the fair-use limit | Wait a moment, then send again |
| **Generation is at capacity right now. Please try again later.** | Free generation is paused for now to protect capacity | Try again later, or upgrade your workspace to a paid plan |
| **Generation is temporarily unavailable. Please try again in a moment.** | Generation could not run just now | Wait a minute and send again |
| **Generation failed. Please try again.** | The turn did not complete; nothing was saved | Select **Try again**, which sends your request again (it is back in the prompt, so you can edit it first) |
| **Stopped. Nothing was changed. Credits for the AI work already underway are still used.** | You stopped the turn | Send the request again when you are ready |
| **This site is still generating.** | A turn is already running on the site, from another tab or another member | Wait for it to finish, then select **Try again**. Only the member who started a turn can stop it |
| **That model isn't available. Pick another model and send again.** | The model you picked is no longer offered | Open **Options** beside send, pick another **Quality**, and send again. See [Models](/products/keystone/models) |
| **This site couldn't be found.** or **That site couldn't be opened.** | The site was deleted, or it belongs to a workspace you are no longer in | Open another site from **Your sites**, or describe a new one |
| **This live site can't move to another workspace from here** | A hosted site moves only with **Move to workspace**, not by publishing to another workspace (or the site is from before Keystone recorded its hosting) | Use **Move to workspace** in its card's menu. See [Move a live site](/products/keystone/workspaces#move-a-live-site) |
| **That workspace's Fractal plan has no room for this site** | The workspace you are moving a live site into has no Fractal plan, or no room for another service or custom domain on it | Choose or upgrade that workspace's Fractal plan, then move the site again. Nothing was changed |
| **Only an owner or admin of both workspaces can move a live site between them** | Moving a live site moves its hosting and code, which takes an owner or admin role in both workspaces | Ask an owner or admin of the other workspace, or have them give you the role |
| **The move stopped partway** | A live site's move was interrupted | The site stays live. Select **Move to workspace** and the same workspace again to finish it |
| **This site is moving to another workspace** | A live site's move is running | Wait for the move to finish, then try again |
| **That workspace has reached its plan's site limit.** | The workspace you are moving a site into has no room for another site | Pick another workspace, or upgrade that workspace's plan. See [Sites](/products/keystone/workspaces#sites) |
| **This site's hosting couldn't be removed right now, so it wasn't deleted.** | Fractal could not take the hosted site offline just then | Try deleting again in a moment |
| **You can't remove this site's hosting in its workspace on Fractal, so it wasn't deleted.** | Your access on Fractal does not let you remove the hosted site's service | Ask a workspace admin to delete it |
| **Only this workspace's owners and admins can delete its sites** (or **move its sites to another workspace**) | Deleting and moving a team workspace's sites needs an owner or admin | Ask a workspace owner or admin |
| **That workspace isn't available to you.** | Keystone could not confirm you are a member of the workspace the builder was opened for | Pick another workspace under **Building in**, or ask a workspace owner to add you |
| **... has used the N sites its plan includes.** | The picked workspace is at its plan's site limit | Select **Upgrade plan** to open the workspace's billing page, select **Open** to keep building its latest site, pick another workspace, or delete a site you no longer need. See [Workspaces and Sites](/products/keystone/workspaces#sites) |
| **This workspace needs a Fractal plan with room for another site.** | The workspace has no Fractal plan (Fractal has no free plan), or its plan has no room for another project or service | Select **Upgrade on Fractal** to choose or upgrade the workspace's Fractal plan, then select **Host on Fractal** again; the preview link works meanwhile |
| **You can't deploy sites in this workspace on Fractal.** | Your access in the workspace does not let you deploy on Fractal | Ask a workspace owner for access; the preview link works meanwhile |
| Publishing gave a preview link instead of a hosted site | You selected **Get a preview link**, or the hosted deploy could not run just now | Select **Host on Fractal**, or try again later |
| A custom domain was not attached | The workspace's Fractal plan has no custom domain left | Upgrade the workspace's [Fractal plan](https://fractal.omni.dev/pricing) and republish |
| A hosted site is slow on the first visit | The site scaled to zero while idle and is waking up | Wait a moment; later visits are fast |
| A product grid says the shop is unavailable | The Halo store could not be reached, or the store domain is wrong | Check the store domain in your prompt and that the store is live |
| A GitHub sync shows **Last push failed** or **GitHub access was removed** | The push did not go through, or the Keystone app lost access to the repository | Check the reason shown, restore the app's access on GitHub if needed, then select **Push now**. See [GitHub Sync](/products/keystone/github-sync) |
| The credit balance is missing from the builder header | The balance only shows on wider screens | Open the workspace's [Billing page](/products/keystone/workspaces#workspace-billing) |
