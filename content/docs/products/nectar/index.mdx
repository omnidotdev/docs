**Omni Nectar** is a free and open-source database visualization and management tool. Connect to your databases, explore schemas visually, and run queries with a modern, intuitive interface. Nectar is licensed under Apache 2.0 and self-hostable.

## Key Features

- **Multi-database support**: connect to PostgreSQL, MySQL, SQLite, and compatible databases
- **Visual schema browser**: explore tables, columns, relationships, and indexes
- **Query editor**: write and execute SQL with syntax highlighting and autocomplete
- **Data grid**: browse and edit data with inline editing, filtering, and sorting
- **Export options**: export data to CSV, JSON, or SQL
- **Connection management**: save and organize multiple database connections
- **Dark and light theme**: persistent theme preference

## Architecture

Nectar's database-browsing UI (data grid, schema viewer, SQL editor) and its data layer live in the standalone `@omnidotdev/nectar-core` package. The Nectar app, built with TanStack Start and React, injects a data source backed by its own server functions. Because the core exposes a `NectarDataSource` interface, the same browser UI can be embedded in other products, each supplying its own data source.
