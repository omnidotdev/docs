Once you are connected, Nectar gives you a schema browser, a SQL query editor, and an editable data grid, all in one interface.

## Schema browser

Explore your database structure visually. The schema browser lets you inspect tables, columns, relationships, and indexes so you can understand how your data fits together.

## Query editor

Write and execute SQL with a modern editor that provides syntax highlighting and schema-aware autocomplete. Nectar keeps a history of your queries so you can review and re-run previous ones.

## Data grid

Browse table data in a grid with inline editing, filtering, and sorting. Edit rows directly in the grid to insert, update, and delete records without writing SQL by hand.

## Exporting data

Export query results and table data for use elsewhere. Nectar supports exporting to:

- CSV
- JSON
- SQL
