Nectar runs in your browser and requires no account to get started. You can use the hosted version or run it locally.

## Hosted version

Open [nectar.omni.dev](https://nectar.omni.dev) in your browser to start exploring right away, with no installation required.

## Run locally

```bash
# Run locally
bunx nectar

# Or use the hosted version
# https://nectar.omni.dev
```

## Next steps

Once Nectar is running, add a database connection and start browsing:

- [Connections](/products/nectar/connections): connect to your databases and manage saved connections.
- [Browsing and Querying](/products/nectar/browsing-and-querying): explore schemas, run SQL, and edit data.
- [Self-Hosting](/products/nectar/self-hosting): run Nectar from source inside your own infrastructure.
