Nectar connects directly to your databases so you can browse and query them from one interface.

## Supported databases

Nectar supports the most common open database engines:

- PostgreSQL
- MySQL and MariaDB
- SQLite
- Any PostgreSQL-, MySQL-, or SQLite-compatible database

## Managing connections

Nectar lets you save and organize multiple database connections, so you can switch between projects and environments without re-entering connection details each time.

<Callout type="info">
  Connections stay local to your session and Nectar collects no telemetry. Your
  credentials and query activity are not sent anywhere beyond the database you
  connect to.
</Callout>

## Read-only connections

Connections can be opened in read-only mode when you only need to browse and query without modifying data, adding a layer of safety when inspecting production or shared databases.
