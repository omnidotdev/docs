**Omni Prism** is privacy-first product analytics. Add one script tag (or the JavaScript client) to a site, app, or docs portal, and Prism reports visitors, pageviews, sessions, sources, and custom events on a dashboard and a GraphQL API.

## How it fits together

- A **workspace** (your Omni workspace) owns one or more **products**. A product is anything you measure: a marketing site, a web app, a docs portal.
- Each product has a public **collector key** (`pk_...`). The key is not a secret: it only routes events to the right product.
- A product can be **locked to a domain**, so events sent from any other site are rejected.
- Events arrive at a public collector, roll up into per-product aggregates every few minutes, and appear on the [dashboard](/products/prism/dashboard).

## The privacy promise

Prism never sets a cookie, never stores a raw IP address, and never builds a profile that follows a person across days or sites. Visitors are counted with a hash that rotates every day, referrers are reduced to a hostname, and query strings are discarded apart from a short whitelist of campaign parameters. See [Privacy](/products/prism/privacy) for exactly what is stored and what is not.

## Self-Hosting

Prism is open source under Apache-2.0. The `prism-stack` repository ships a Docker Compose stack (Postgres, the API, and the dashboard) that runs against any OpenID Connect provider, with no plan limits. See [Self-Hosting](/products/prism/self-hosting).
