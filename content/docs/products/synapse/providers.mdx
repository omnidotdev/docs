Synapse supports multiple providers across five modalities. This page covers configuration for each provider.

## LLM Providers

| Provider | Config `type` | Models |
|----------|---------------|--------|
| Anthropic | `anthropic` | Claude Opus 4.6, Claude Sonnet 4.5, Claude Sonnet 4, Claude Haiku 4.5 |
| OpenAI | `openai` | GPT-4o, GPT-4o mini, o3-mini |
| Google | `google` | Gemini 2.5 Pro, Gemini 2.5 Flash |
| OpenAI-compatible | `openai` (with custom `base_url`) | Any model served by an OpenAI-compatible API, such as a self-hosted inference server |
| AWS Bedrock | `bedrock` | Claude, Titan, and other Bedrock-hosted models |

### Anthropic

```toml
[llm.providers.anthropic]
type = "anthropic"
api_key = "{{ env.ANTHROPIC_API_KEY }}"
```

### OpenAI

```toml
[llm.providers.openai]
type = "openai"
api_key = "{{ env.OPENAI_API_KEY }}"
```

### Google

```toml
[llm.providers.google]
type = "google"
api_key = "{{ env.GOOGLE_API_KEY }}"
```

### OpenAI-compatible endpoints

Any API that speaks the OpenAI chat completions protocol works with the `openai` type and a custom `base_url`. Name the provider whatever you like; requests address its models as `<name>/<model>`:

```toml
[llm.providers.local]
type = "openai"
base_url = "https://llm.example.com/v1"
api_key = "{{ env.LOCAL_LLM_API_KEY }}"
```

<Callout type="warning">
  Check the upstream's terms before routing production traffic through it. Some hosted APIs allow trial or evaluation use only.
</Callout>

### AWS Bedrock

```toml
[llm.providers.bedrock]
type = "bedrock"
region = "us-east-1"
access_key_id = "{{ env.AWS_ACCESS_KEY_ID }}"
secret_access_key = "{{ env.AWS_SECRET_ACCESS_KEY }}"
```

<Callout type="info">
  Bedrock authentication also supports IAM roles and instance profiles. Omit `access_key_id` and `secret_access_key` to use the default AWS credential chain.
</Callout>

## Common Provider Fields

All providers share these optional configuration fields:

| Field | Description | Default |
|-------|-------------|---------|
| `type` | Provider type identifier (required) | -- |
| `api_key` | API key for authentication | -- |
| `base_url` | Custom base URL for self-hosted or proxy endpoints | Provider default |

### Custom Base URL

Use `base_url` to point at a self-hosted or proxy endpoint:

```toml
[llm.providers.local]
type = "openai"
base_url = "http://localhost:8080/v1"
api_key = "not-needed"
```

## BYOK (Bring Your Own Key)

Each provider is configured with your own API key. Synapse never stores or transmits keys except to the upstream provider. See [synapse.omni.dev/pricing](https://synapse.omni.dev/pricing) for managed key alternatives.
