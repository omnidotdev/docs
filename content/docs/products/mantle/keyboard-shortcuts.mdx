## Command palette

Press **⌘ K** on a Mac or **Ctrl K** on Windows and Linux, or select **Search or
jump to** in the top bar, to open the command palette. Type to filter, use the
arrow keys to move, and press **Enter** to run a command.

| Group | Commands |
| --- | --- |
| Navigation | **Home**, **Dashboard**, **People**, **Inventory**, **Invoices**, **Quotes**, **Settings** |
| Preferences | **Switch to dark theme** or **Switch to light theme**, **Keyboard shortcuts** |

Workspace pages (Dashboard through Settings) are listed while you are inside a
workspace. Commands also match related words, so typing "contacts" or
"companies" finds **People**, and "products" finds **Inventory**.

## Global shortcuts

| Shortcut | Action |
| --- | --- |
| **⌘ K** / **Ctrl K** | Open the command palette |
| **?** | Show keyboard shortcuts |
| **B** | Collapse or expand the sidebar |
| **T** | Toggle the light and dark theme |
| **Esc** | Close the sidebar on a phone, or close an open dialog |

Single-key shortcuts do not fire while you are typing in a field, so they never
get in the way of filling in a form.

## Other keys

- In a contact's **Tags**, press **Enter** or **,** to add the tag you typed.
- In a contact's **Email addresses**, press **Enter** to add the address.
- In a quote's deliverables, acceptance criteria, and additional terms, press
  **Enter** to add the entry you typed.
- In lists, rows can be reached with **Tab** and opened with **Enter** or
  **Space**.
