<Callout type="info">
  A public creator API is **planned, not yet available**. This page describes
  the intended direction so you can plan ahead, not a feature you can use today.
  Nothing here is a live contract.
</Callout>

Crystal does not yet offer creator API keys or a documented public API. The
GraphQL endpoint that powers the dashboard is an internal interface for the
Crystal app, not a supported integration surface, so treat it as off-limits: it
is unauthenticated for third parties, undocumented, and free to change without
notice.

## What is planned

The goal is to make the same data that powers your dashboard, your tiers, goals,
supporters, digital products, and earnings, available programmatically so you
can build on top of your creator business. Uses that path would open up include:

- Syncing your supporters or sponsorship activity into your own tools
- Reporting on earnings and payouts outside the dashboard
- Automating actions when a new supporter joins or a goal is reached

When programmatic access ships, it will arrive with creator-scoped
authentication and a published, versioned reference. This page will be updated
to describe how to generate a key and which operations are supported.

If you have a specific integration in mind, reach out through your Crystal
dashboard so your use case can inform what gets built first.
