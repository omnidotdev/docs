title: API
description: Programmatic access to your Crystal data (paid plans)
---

<Callout type="info">
  API access is included on the **Pro** and **Team** plans. See
  [payments and fees](/products/crystal/payments-fees) for the plan comparison.
</Callout>

Crystal is built API-first: the same data that powers your dashboard (your
tiers, goals, supporters, digital products, and earnings) is available
programmatically so you can build on top of your creator business.

Typical uses include:

- Syncing your supporters or sponsorship activity into your own tools
- Reporting on earnings and payouts outside the dashboard
- Automating actions when a new supporter joins or a goal is reached

<Callout type="warn">
  A published, stable public API reference is still being finalized as Crystal
  moves toward general availability. This page describes the direction, not yet
  a frozen contract, so treat details as subject to change.
</Callout>

If you want early access or have a specific integration in mind, reach out
through your Crystal dashboard so we can point you at the current endpoints and
authentication details for your account.
