**Omni Harmony** is a templating and syncing engine for project files. It goes beyond one-time scaffolding: Harmony maintains a connection between your project and its source template, applying template updates over time while preserving local edits.

## Documentation coming soon

Full documentation is on the way. In the meantime:

- Visit [harmony.omni.dev](https://harmony.omni.dev) for an overview
- See the [README](https://github.com/omnidotdev/harmony-cli#readme) for installation and a quick start
- Run `harmony --help` for the command reference
