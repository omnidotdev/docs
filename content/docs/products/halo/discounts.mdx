Create discounts from **Marketing → Discounts**. A discount reduces an order's total at checkout, either when a buyer enters its code or automatically.

## Basic discounts

A basic discount is a single code with a percentage, fixed-amount, or free-shipping value. Set an optional minimum purchase, a total usage limit, and a start and end date. Basic codes are available on every plan.

## Scope

By default a discount applies to the whole order. You can instead scope it to specific products, collections, or customer groups so it only applies to matching items.

## Advanced discounts

Advanced discount behavior is available on the Pro and Team plans (see [Pricing](/products/halo/pricing)):

- **Automatic**: Apply with no code entered, so qualifying carts are discounted automatically.
- **Per-customer limits**: Cap how many times a single customer can use a discount.
- **Multi-target scope**: Target several products or collections at once.
- **Stacking rules**: Control whether a discount combines with other product or shipping discounts.
