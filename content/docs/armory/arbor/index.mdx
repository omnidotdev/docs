**Omni Arbor** is a git-native, graph-UI git provider for visualizing and modeling multi-repository setups. Instead of treating every repository as an isolated silo, Arbor renders your organization as a graph of repositories and the relationships between them, making complex microservice and polyrepo architectures easy to understand at a glance. It is powered by [🕸️ Weaver](/armory/weaver) for dependency-aware multi-repository orchestration.

Arbor is open source under the Apache 2.0 license and fully self-hostable via Docker Compose.

## Key Features

- **Graph-based visualization**: Understand complex repository relationships intuitively
- **Multi-repo modeling**: Work with distributed, polyrepo codebases as a single connected graph
- **Microservice-friendly**: A tagging system designed for microservice architectures
- **Weaver integration**: Reuse Weaver dependency definitions to lay out and sync your repositories
- **Git-native backend**: A high-performance Rust git service handles storage and transport
- **Self-hostable**: Run the entire stack on your own infrastructure

## Use Cases

- **Complex projects**: Visualize and manage multi-repository projects
- **Microservice development**: Streamline workflows across many small services
- **Team collaboration**: Improve visibility into code relationships across teams
- **System architecture**: Model and document system components and their interactions
